# gopython v0.0.0

This is the first scaffold release for gopython.

It sets up the public repository, Go module, README, CI, release workflow, and
the tracked CPython `Python/` source inventory. It does not include a Python
interpreter yet.

## Included

- `gopython-linux-amd64`
- `gopython-linux-arm64`
- `gopython-darwin-amd64`
- `gopython-darwin-arm64`
- `gopython-windows-amd64.exe`
- `gopython-windows-arm64.exe`
- `checksums.txt`

## Notes

Use this release only to verify the repository and release pipeline. Real
CPython migrations start after this tag, one reviewed pull request at a time.
