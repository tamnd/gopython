# gopython v0.2.0

This release ports the Phase 2 platform and runtime substrate from CPython's
`Python/` directory into Go.

The repository still does not execute Python source. This release builds the
OS, time, thread, lock, loader, and profiling layers that later interpreter
work will stand on.

## Included

- File descriptor duplication, file status, path, locale-encoding, and file
  opening helpers.
- Path configuration storage and `sys.path[0]` style derivation.
- CPython-style time conversion, clock reporting, and deadline helpers.
- Thread lifecycle, thread-local storage, native thread id helpers, condition
  variables, locks, parking, critical sections, QSBR, BRC, and stackref state.
- Dynamic loader entry points across Unix, Windows, and stub platforms.
- Emscripten syscall and trampoline shims.
- Perf map and jitdump trampoline writers.

## Validation

The release was prepared with unit tests, race tests, static checks, source
inventory validation, and cross-platform CI on Ubuntu, macOS, and Windows.

## Notes

This is still infrastructure work. Interpreter configuration, process
lifecycle, and runtime state begin in the next phase.
