# gopython v0.1.0

This release ports the Phase 1 CPython `Python/` helper files into Go.

The work is still below interpreter level. There is no parser, compiler, VM,
or Python execution support yet. The new code is the low-level helper layer
that later migrations will build on.

## Included

- CPython byte classification and ASCII case helpers.
- CPython string comparison and hex formatting helpers.
- CPython long parsing and snprintf boundary behavior.
- Version, platform, compiler, copyright, config, math, and FPE helpers.
- The generated CPython stdlib module name list.
- The CPython suggestions edit-distance helper.
- Unique ID, object stack, index pool, hash table, arena, and hash helpers.

## Validation

The release was prepared with unit tests, static checks, Markdown lint, source
inventory validation, and release target cross-builds.

## Notes

This is a helper-layer release. Real Python source execution starts in later
migration phases.
